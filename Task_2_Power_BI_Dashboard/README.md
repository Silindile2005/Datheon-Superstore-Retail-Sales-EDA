Task 2: Superstore Executive Dashboard

Project Overview

This project develops an interactive executive dashboard using Microsoft Power BI to analyse Superstore retail sales performance, profitability, order volumes and product performance.

Objectives

Monitor key performance indicators (KPIs).

Analyse monthly sales trends and year-over-year sales growth.

Compare sales performance across product categories and sub-categories.

Evaluate product profitability.

Enable interactive filtering by date and geographical region.

Tools and Technologies

Microsoft Power BI Desktop

Power Query for data cleaning and transformation

DAX for calculated measures

GitHub for project documentation and version control

Data Preparation

The Superstore sales dataset was cleaned and transformed into a star-schema data model consisting of:

Fact_Orders

Dim_Customer

Dim_Product

Dim_Date

The cleaned dataset contains 9994 sales records.

Dashboard Features

Total Sales, Total Profit, Total Orders and Profit Margin KPI cards

Year-over-Year Sales Growth line chart

Monthly Sales Trend line chart

Category and Sub-Category Sales Treemap

Product Profitability Matrix with conditional formatting

Interactive Date and Region slicers

Deliverables

Superstore_Executive_Dashboard.pbix — Interactive Power BI report

Superstore_Executive_Dashboard.pdf — Exported executive dashboard

Conclusion

The dashboard provides an interactive overview of Superstore's sales and profitability, allowing users to identify trends, compare product performance and explore regional differences.
